# Kishore Theiveekan: Portfolio

Personal portfolio of a frontend engineer. Next.js 16 static export with three.js scenes, scroll choreography and pre-rendered case studies.

- Every page is plain HTML at build time, so search engines and AI crawlers read the real content.
- The 3D city adapts on phones, and a reduced-motion mode shows all content without animation.
- `npm test` checks routes, overflow at six widths, console errors and links in real Chrome.

```bash
npm install
npm run dev     # local development
npm run build   # static site in out/
npm test        # release checks, after a build
```

Designed in Claude Design and built with AI-assisted development.
